КРАТКОЕ ПОЯСНЕНИЕ ПРОЕКТА

Проект реализует сервер конкурса грантов с хранением данных в оперативной памяти.

1. server.Server собирает зависимости и передаёт готовые сервисы в api.Server.
2. API принимает JSON, создаёт объекты Request, вызывает сервисы, получает внутренние Result и преобразует их в Response.
3. Каждый публичный метод сервера возвращает ServerResponse: код 200 при успехе или 400 с JSON-полем error при ошибке.
4. Application Services содержат правила регистрации, подачи заявок, оценивания и распределения грантов. Они не возвращают ServerResponse и не зависят от API DTO.
5. Application Results и Commands передают данные между слоями без зависимости от внешнего JSON-формата.
6. DAO-интерфейсы находятся в application/ports, реализации — в infrastructure/persistence.
7. Domain содержит модели и Database с коллекциями; данные хранятся только в оперативной памяти.
8. Роль администратора удалена, потому что техническое задание её не предусматривает.

Направление зависимостей: API -> Application -> Domain. Слой Application получает доступ к хранению через интерфейсы; инфраструктурные реализации подключаются в server.Server.

Откройте папку проекта в IntelliJ IDEA как Maven-проект. Нужна Java 17 или новее. Тесты запускаются из src/test/java или командой mvn test.
