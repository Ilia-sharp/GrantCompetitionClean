# Конкурс грантов

Java-проект сервера конкурса грантов. Все данные хранятся в оперативной памяти и исчезают после очистки базы или перезапуска приложения.

## Архитектура

- `api` — внешний слой: `Server`, JSON, DTO запросов и ответов, единый `ServerResponse`.
- `application/services` — сценарии регистрации, заявок, оценок и подведения итогов.
- `application/commands` — входные команды для сценариев приложения.
- `application/results` — внутренние результаты сценариев, не зависящие от API.
- `application/ports` — интерфейсы для доступа к данным.
- `domain/models` и `domain/Database.java` — модели и хранение данных в памяти.
- `infrastructure/persistence` — реализации интерфейсов доступа к данным.
- `server/Server.java` — сборка зависимостей и публичный фасад для вызова операций.

Зависимости основных слоёв направлены внутрь: `API → Application → Domain`. Application-слой обращается к хранилищу через интерфейсы из `application/ports`; реализации этих интерфейсов находятся в инфраструктуре. Класс `server.Server` собирает реализации и передаёт сервисы в API через конструктор.

API преобразует JSON в DTO запросов, вызывает сервисы, преобразует внутренние `Result` в DTO ответов и возвращает `ServerResponse`. Сервисы не принимают JSON, не импортируют API DTO и не возвращают `ServerResponse`. Любой публичный метод сервера возвращает один формат ответа: `200` при успехе либо `400` с JSON-полем `error` при ошибке.

## Реализовано

Участники могут регистрироваться, входить и выходить, удалять аккаунт, создавать несколько заявок и отменять свои заявки. Эксперты регистрируются с направлениями, смотрят подходящие заявки, ставят оценки от `1` до `5`, меняют и удаляют их. Подведение итогов ранжирует заявки по средней оценке по убыванию, затем по запрашиваемой сумме по возрастанию; при равных оценках и суммах порядок случайный. Заявки с оценкой не выше порога прекращают дальнейшее распределение фонда. Администратор не добавлялся, так как такой роли нет в техническом задании.

## Открытие и запуск в IntelliJ IDEA

Откройте папку проекта как Maven-проект и дождитесь загрузки зависимостей. Используется Java 17 или новее. Запустите тесты из `src/test/java` или выполните `mvn test` в терминале.
